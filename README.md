# Server Stats

A bash script to analyse basic server performance stats on any Linux server.

## What it shows
- CPU usage
- Memory usage (used vs free)
- Disk usage (used vs free)
- Top 5 processes by CPU
- Top 5 processes by memory

## How to run

1. Clone the repository
git clone https://github.com/SarahBoNjoroge/server-stats.git

2. Move into the folder
cd server-stats

3. Make the script executable
chmod +x server-stats.sh

4. Run it
./server-stats.sh
